## Краткая сводка решений

- Монорепо, один Python-пакет `notes_bot`, три Docker-образа: `app`, `app-heavy`, `embeddings`.
- Пять единиц развёртывания: бот, быстрый воркер, тяжёлый воркер, embedding-сервис, GC CronJob.
- Три очереди RQ: `fast` (текст, страницы), `heavy` (yt-dlp, Whisper), `llm` (обогащение и синтез `/smart_search` через ai-proxy).
- Приватность по умолчанию `private` - кнопки в чате это переключатель, а не блокирующий шаг.
- В группах сохраняются только упоминания бота и ответы на его сообщения, а не вся переписка.
- Голосовые заметки от пользователя транскрибируются тем же Whisper, что и аудио из Instagram.
- Поиск двухфазный: ANN top-K по чанкам, затем дедуп по заметке, затем страница из кеша в Redis.
- `/smart_search` асинхронный: обычная выдача сразу, синтез ответа через ai-proxy приходит новым сообщением.
- Контракт ai-proxy зафиксирован (провайдер `codex`); выбор embedding-модели изолирован сервисом и не блокирует разработку.
- `LLM_ENABLED=true` включается только после фикса песочницы codex в ai-proxy (ADR-14, риск R5).
